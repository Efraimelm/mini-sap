# Mini SAP GUI

Simulador em HTML do SAP GUI (tema Belize) para praticar a determinação de preço em SD.

Transações disponíveis:

- **V/08** – Esquemas de cálculo (procedimentos → etapas de controle)
- **V/06** – Tipos de condição (detalhe com a sequência de acesso)
- **V/07** – Sequências de acesso (acessos → campos)

Atalhos: `Enter` executa · `F3` volta · `Ctrl+F` procura · `Ctrl+G` continua a procura · `F2` abre o detalhe

Para usar, abra o `index.html` no navegador. Não precisa instalar nada.
